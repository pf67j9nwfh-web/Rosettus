# PowerPC preference panes

Open `/Applications/Rosettus Preference Pane Viewer.app` on Mojave. The native browser finds bundles containing 32-bit PowerPC code in `~/Library/PreferencePanes`, `/Library/PreferencePanes`, and `/Network/Library/PreferencePanes`. Select a pane and click **Open Pane**, or double-click its row. **Refresh** rescans these directories. **Other…** opens a file chooser for a `.prefPane` anywhere on disk. Finder's **Open With** also supports the viewer; it is registered as an alternate handler and does not replace System Preferences.

The browser checks executable architecture without loading third-party code. It sets `OAH_NO_CPPATCH=1` for its pane processes to avoid a concurrent commpage JIT rewrite crash in background workers; an explicit caller setting takes precedence. Each pane runs in a separate PowerPC host using Rosettus and the exported Snow Leopard PreferencePanes framework. A pane failure does not take down the browser or another pane. The pane host implements selection, keyboard focus, text editing commit on close, cancellation, and deferred unselection. Quit or the red close button closes that pane's host. The browser can be closed independently.

Logs are written to `~/Library/Logs/Rosettus/PreferencePanes/`, one file per launch. A pane's own helper programs, services, or privileges may still need compatibility work; displaying a pane does not make its background service compatible with Mojave. Intel-only panes belong in System Preferences.

The viewer and each launched pane host use the local System Preferences icon. The installer copies it from Mojave into the installed bundles; Apple artwork is not included in the repository. Rosettus Launcher uses an original metallic gear and blue play-button icon generated by `src/launcher/mkicon.m`.

## Adobe Version Cue CS2

The installed `/Library/PreferencePanes/Version Cue CS2.prefPane` is detected and its original GUI loads. The host redirects its Java preflight through Rosettus's `rjava` wrapper, ensuring that the exported PowerPC Java runs instead of Mojave's native Java launcher. Install the optional PowerPC Java export first.

The optional [Version Cue background service](VERSION_CUE.md) starts the original Adobe server and provides its control/status ports. With that service installed, the pane shows **On** and enables its server controls. The runtime uses a patched copy of Adobe's launcher; the original Adobe bundles and system Java paths remain unchanged.

## Build

On Snow Leopard with Xcode 3.2 and the PowerPC compiler:

```
bash src/prefpanes/build.sh host
```

Copy `bin/prefpanes/` to the Mojave repository. On Mojave with the Command Line Tools:

```
bash src/prefpanes/build.sh viewer
```

`install.sh` copies the host to `$ROOT/prefpanes/` and the browser to `$APPDIR`, recording a custom runtime root in the browser plist and signing the resulting app. The package includes both through its existing `bin/` payload. `uninstall.sh` removes the browser and the runtime host. No Apple files are included in these binaries.

## Verification

Tested on Mojave:

- Native browser detects installed Adobe Version Cue CS2.
- Manual **Other…** chooser opens a PowerPC fixture outside installed pane directories, with a per-launch log.
- A fixture button receives its PowerPC action; normal close calls `willUnselect` and `didUnselect` and exits.
- `NSUnselectCancel` keeps the host open.
- `NSUnselectLater` keeps the event loop running until `replyToShouldUnselect:YES`, then calls unselection hooks and exits.
- Adobe's pane loads, reaches `didSelect`, and shows On with the optional background service running. Viewer launches disable concurrent commpage rewriting after a background-thread crash exposed that incompatibility.
- Both builds complete with `-Wall`; installer/uninstaller/build shell syntax checks pass.

`src/prefpanes/TestPane.m` and `TestPane.plist` are the reproducible fixture. To build it on Snow Leopard without installing anything:

```
mkdir -p /tmp/RosettusTest.prefPane/Contents/MacOS
cp src/prefpanes/TestPane.plist /tmp/RosettusTest.prefPane/Contents/Info.plist
gcc -arch ppc -bundle -O2 -Wall -framework Cocoa -framework PreferencePanes \
    src/prefpanes/TestPane.m -o /tmp/RosettusTest.prefPane/Contents/MacOS/TestPane
```

Copy the fixture to Mojave and choose it with **Other…**. For lifecycle tests, run the installed host through `rosettus` with `OAH_NO_CPPATCH=1` and environment variable `RPP_TEST_UNSELECT=cancel` or `later`; the fixture reports its lifecycle to stderr. The fixture is source only and is not installed with the viewer.
